# CS2

Проекты про скины и рынок Counter-Strike 2. Каждый проект лежит в своей папке и открывается как отдельная страница на GitHub Pages.

Главная: https://terbiuz.github.io/cs2/

| Проект | Папка | Адрес |
| --- | --- | --- |
| Инвестиционный анализ скинов: supply, цены по wear, статус кейсов, ликвидность, тренд и метки | [`investments-analysis`](investments-analysis) | https://terbiuz.github.io/cs2/investments-analysis/ |

Чтобы добавить проект: создайте папку со своим `index.html`, добавьте карточку на главную (`index.html` в корне) и строку в эту таблицу.

Это не финансовый совет. Сайт не связан с Valve, CSFloat или Skinport.
